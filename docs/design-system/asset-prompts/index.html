2D asset generation brief

Model-ready prompts (Midjourney / DALL·E / SDXL) to replace the emoji & flat-color placeholders, with exact filenames and pixel specs. Every prompt carries the shared style stem and palette so the set stays cohesive. Each asset lists how it must read at game zoom.

Drop generated files at the listed public/assets/… paths. Use the per-asset Copy prompt button, or grab the whole set as a CSV (filename,spec,group,prompt) for batch import.

Global style — every asset

Gritty militarized near-future dieselpunk, lightly stylized for readability. Silhouette-first (readable as solid black at 32px). Desaturated world; color is a sparse signal. PBR-plausible materials, subtle grain. No neon/fantasy/cartoon gloss, no centered-on-gradient, no rainbow, no lens flare, no AI-melted detail. Max 2 accent colors per asset.
